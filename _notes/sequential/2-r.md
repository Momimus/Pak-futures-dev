### 1.1. Add a Post

- We can click on **Create Post**
- It allows writing HTML or edit in "Compose Mode" (which generates HTML eventually)
- Link always has format `{base}/{yyyy}/{mm}/permalink.html`. e.g., `https://theneweratechcommunity.blogspot.com/2025/10/simlpe-post.html`
- permalink can be auto-gen (from title) or custom entered.

### 1.2. Add Pages

- We can create a page using **Create Page**
- Just like post it has HTML and compose
- Page url format is `{base}/p/{perma}.html`.
- Amazingly there is no way to change permalink. But it is created from title when u create page. and if u later edit page title, the perma remains the same (cool hack).
- I created page at [This link](https://theneweratechcommunity.blogspot.com/p/test.html) to test.
